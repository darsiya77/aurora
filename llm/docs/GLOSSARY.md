# Словарь простыми словами

- **Языковая модель (LLM)** — программа, которая по началу текста угадывает следующий кусочек. Из миллиардов таких угадываний получаются связные ответы.
- **Токен** — кусочек текста: слово, часть слова или знак. «Инвестиции» может быть 1–3 токенами.
- **Токенизатор** — словарь токенов и правила, как резать текст. Мы обучаем его на своём корпусе, чтобы русские слова резались экономно.
- **Параметры** — числа внутри модели, которые подстраиваются при обучении. «1,2 млрд параметров» — размер модели.
- **Предобучение** — обучение на больших объёмах обычного текста: модель учит язык и факты.
- **Дообучение (SFT)** — обучение на примерах диалогов: модель учится быть помощником.
- **LoRA** — дешёвое дообучение: меняем не всю модель, а небольшие добавочные слои.
- **DPO** — обучение на парах «хороший ответ / плохой ответ».
- **Функция потерь (loss)** — насколько модель ошибается в угадывании. Должна падать.
- **Перплексия** — та же ошибка в понятной шкале: «из скольких вариантов модель в среднем сомневается». Меньше — лучше.
- **Чекпоинт** — сохранённое состояние модели, с которого можно продолжить или которое можно запустить.
- **GPU-час** — час работы одной видеокарты; основная единица стоимости обучения.
- **Контекст** — сколько токенов модель видит одновременно (`max_seq_len`).
- **Квантование** — сжатие модели для быстрой и дешёвой работы с небольшой потерей качества.
